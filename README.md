# Website Repository

This repository contains the source code for my personal website built with [Quarto](https://quarto.org/), designed to showcase my academic background, research interests, projects, and professional activities.

https://aarredondoc.github.io/andresarredondo/

## 🌐 About the Website

The website serves as a personal academic and professional portfolio, including sections such as:

- About Me
- Research Interests
- Projects
- Publications
- CV
- Teaching and Outreach
- Contact Information

It is developed using Quarto, allowing reproducible content generation and easy deployment.

## 🛠 Technologies Used

- Quarto
- Markdown
- HTML / CSS
- YAML
- GitHub Pages (for deployment)
